# E-Commerce Cloud Native

Repositorio del proyecto desarrollado para la asignatura **Desarrollo Cloud Native**.

El proyecto consiste en el desarrollo de una plataforma de **E-Commerce**, utilizando **React** para el frontend y **Java con Spring Boot** para el backend.

Durante el desarrollo se utilizarán servicios de **AWS** y **Microsoft Azure**, aplicando conceptos relacionados con el desarrollo y despliegue de aplicaciones Cloud Native.

## Tecnologías

* React
* Java
* Spring Boot
* Docker
* AWS
* Microsoft Azure
* Git / GitHub

## Descripción

La aplicación busca implementar una plataforma de comercio electrónico con funcionalidades como:

* Gestión y visualización de productos.
* Usuarios y autenticación.
* Carrito de compras.
* Gestión de pedidos.

La arquitectura y los servicios Cloud utilizados se irán definiendo durante el desarrollo del proyecto.
